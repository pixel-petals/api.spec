# @pixel-petals/org.template

Organization template repository.

## Structure

| Folder | Contains | Use when |
| --- | --- | --- |
| [`apps/`](apps/README.md) | Deployable applications | The output is a running service, site, or binary; built on top of `packages/` |
| [`packages/`](packages/README.md) | Shared libraries | The output is imported by apps or other packages |
| [`plugins/`](plugins/README.md) | Extensions | The output extends a tool, platform, or build system |
| [`utils/`](utils/README.md) | Generic utilities | The output is app/package-neutral and broadly reusable |
